# AIOS Track 1

Командный репозиторий решения задачи «Мультиагентная система оптимального управления на основе гидродинамической модели».

## Цель

Создать воспроизводимый контур управления: получить состояние модели, выбрать управляющее воздействие, применить его и оценить новый результат с учётом физических и технологических ограничений. Целевая экономическая метрика — NPV.

## Текущий статус

Подготовлена минимальная основа проекта. Предметная модель, адаптер симулятора и алгоритмы управления будут добавляться отдельными задачами после разбора официальных материалов трека.

## Запуск

```bash
mise install
mise run bootstrap
mise run check
```

## Работа с кодом

Каждая задача выполняется в отдельной ветке и проходит через pull request. Ветка `main` напрямую не изменяется.
