# AIOS Track 1

Командный репозиторий решения задачи «Мультиагентная система оптимального управления на основе гидродинамической модели».

## Цель

Создать воспроизводимый контур управления: получить состояние модели, выбрать управляющее воздействие, применить его и оценить новый результат с учётом физических и технологических ограничений. Целевая экономическая метрика — NPV.

## Текущий статус

Работает сквозной контур сабмишена: кейс → расписание скважин → OPM Flow → официальный расчёт ЧДД → пакет сабмишена. Политика управления пока тривиальная (продолжение baseline), оптимизатора нет. Подробности — [docs/validation_pipeline.md](docs/validation_pipeline.md).

## Запуск

```bash
mise install
mise run bootstrap
mise run check
```

Сквозной прогон (нужен запущенный Docker):

```bash
mise run validation-demo
```

Экран перераспределения закачки EXP-001 — [docs/exp001_injection_screen.md](docs/exp001_injection_screen.md):

```bash
mise run exp001
```

Конверт робастности EXP-003 — [docs/exp003_robustness_envelope.md](docs/exp003_robustness_envelope.md):

```bash
mise run exp003
```

Демонстрация КТ1 — проверенный снимок экспериментов, без Docker:

```bash
mise run kt1-demo
```

## Работа с кодом

Каждая задача выполняется в отдельной ветке и проходит через pull request. Ветка `main` напрямую не изменяется.
