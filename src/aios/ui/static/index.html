Команда magic Трек 01 · Model Y · 2014-2015

Гибридная
MAS

Языковая модель предлагает, что делать со скважинами. Детерминированный код решает, сколько. Физику считает OPM Flow, экономику считает официальный калькулятор ЧДД.

Решение команды magic: замкнутый контур управления заводнением. Управляющие последовательности → симулятор → расчёт ЧДД, и каждый шаг виден на графе.

Шаг 1

Окружение

Для прогона нужны колода Model Y, официальный калькулятор ЧДД и Docker с образом OPM. Пути задаются в .env, страница проверяет их сама.

Готовность окружения

Проверяю…

Колода, калькулятор, Docker, провайдер и пакет сабмишена.

Как пользоваться

  1. Окружение зелёноеЕсли что-то красное, поправьте путь в .env и нажмите «Проверить снова».
  2. Нажмите «Запустить сквозной прогон»Сданные управляющие последовательности уйдут в OPM, траектория в калькулятор ЧДД, результат сверится с заявкой. Около двух минут.
  3. Смотрите на графРаботающий узел подсвечен. Клик по любому узлу показывает, что он делает и что он выдал.

Локальный запуск

То же самое из терминала

Страница запускает те же команды. Материалы организаторов в репозиторий не входят, пути к ним указываются в .env.

# один раз на свежем клоне
mise trust && mise install && mise run bootstrap
cp .env.example .env               # MODEL_Y_ROOT и CHDD_ROOT: пути к материалам организаторов
docker pull openporousmedia/opmreleases@sha256:…

# эта страница
mise run ui

# то же самое из терминала
mise run verify                    # сквозной прогон: сданные последовательности → OPM → ЧДД, ход печатается сразу
mise run validation-demo           # сквозной прогон опорной политики и пакет сабмишена
mise run progress                  # ход идущего прогона OPM в соседней вкладке
