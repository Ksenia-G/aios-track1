**Внутренние заметки докладчика КТ1: ИСКЛЮЧЕНЫ ИЗ ПУБЛИКУЕМОЙ ИСТОРИИ.**

Недостаточно удалить такой файл в последнем коммите: он остался бы
достижим через более ранние коммиты и ушёл бы на сервер вместе с ними.

```bash

git rev-list --objects release/kt1-github-candidate | grep <путь>  # пусто

```

Достижимые с ветки пути внутри `docs/` перечисляются одной командой и
содержат только техническую документацию:

```bash
git rev-list --objects release/kt1-github-candidate \
  | awk 'NF>1 {print $2}' | sort -u | grep '^docs/'
```

Отдельный коммит-удаление не понадобился и не создавался: файла нет ни в

### Что входит

- исходный код (`src/aios/`): контракт кейса, расписание, адаптеры OPM и
  ЧДД, сквозной контур, эксперименты, демонстрационный слой;
- кейс управления (`cases/`) — с внешними путями через переменные окружения;
- документация (`docs/`) -- методические документы контура и экспериментов;
- агрегированные свидетельства экспериментов (`experiments/`): CSV, JSON,
  снимок для демонстрации. Всё детерминировано, легко и пригодно для аудита;
- тесты (`tests/`);
- конфигурация сборки: `mise.toml`, `pyproject.toml`, `uv.lock`,
  `.gitignore`, `.env.example`.

### Что не входит намеренно

- колода Model Y и любые её бинарные файлы (`EGRID`, `INIT`, `UNRST`,
  `SMSPEC`, `UNSMRY`, `PRT`, `DBG`, архивы);
- официальный пакет расчёта ЧДД (`CHDD_PYTHON`);
- сырые выходы симулятора и рабочие каталоги прогонов (`*/runtime/`);
- полные лабораторные CSV;
- кеши Python, pytest, ruff, окружение `.venv`;
- локальный файл `.env` с личными путями;
- внутренние заметки докладчика для репетиции показа КТ1: это не
  техническая документация и не продуктовый материал. Они исключены из
  публикуемой истории целиком, а не только из последнего состояния. Сама
  демонстрация (`mise run kt1-demo`), её код и снимок результатов входят
  в публикацию;
- секреты, токены, учётные данные.

## Требуемая конфигурация

Внешние материалы задаются переменными окружения; править исходный код не
нужно:

```
MODEL_Y_ROOT=/path/to/model-y      # каталог с MODEL_Y.DATA
CHDD_ROOT=/path/to/chdd-python     # каталог с chdd_model.py
```

Пример — `.env.example`. Файл `.env` не отслеживается. Без этих переменных
работают `mise run check` и `mise run kt1-demo`; живые прогоны
останавливаются и называют незаданную переменную.

Для живых прогонов дополнительно нужен Docker: симулятор берётся из
закреплённого по digest образа.

## Известные ограничения

1. Массовый мост между объёмами OPM и массами калькулятора не сверен с
   эталонной выгрузкой tNavigator.
2. Водный учёт поверхностный, по модели; официальное правило водного
   баланса не определено.
3. Порог по пластовому давлению не задан, давление остаётся метрикой риска.
4. Лучший кандидат получен на границе проверенного диапазона добавочной
   закачки: рост ЧДД там не исчерпан.
5. Это лучший из проверенных кандидатов, а не глобальный оптимум.
